마스터 데이터 관리

연차 신청에 쓰이는 시간대와 결재·백업 같은 시스템 설정을 한곳에서 다룹니다.

업무 규칙 설정

승인 워크플로우 — 현재: {% if is_approval_required %}켜짐 (결재 필요){% else %}꺼짐 (즉시 승인){% endif %}

꺼짐: 사원이 신청하면 바로 «승인됨»으로 기록됩니다.
켜짐: 신규 신청은 «결재 대기»로 들어가며, 관리자 또는 팀장이 타임라인에서 승인·반려·취소 처리합니다.

캘린더 공유 범위 설정 — 현재: {% if company_calendar_visible %} 전사 공유 {% elif team_calendar_visible %} 소속 팀원 공유 {% else %} 공유 안 함 (본인 전용) {% endif %}

일반 사원 및 팀장이 조회할 수 있는 연차 캘린더의 범위를 지정합니다.

시간 단위/업무시간/점심시간 정책

입력 제어용 최소 단위입니다. 실제 차감은 선택 구간에서 점심시간 제외 후 계산됩니다.

2) 업무시간 범위

신청 화면은 이 구간만 표시됩니다.

3) 점심시간 제외(선택)

각 값은 차감시간 계산에서 자동 제외됩니다.

입력 시각은 선택된 단위 경계값만 허용되며, 사용자 신청 화면은 업무시간 범위만 표시됩니다. 단위는 입력 제어용이고 실제 차감시간은 선택 구간에서 점심 제외 후 계산됩니다.

시스템 운영 작업

표시 이름(브랜딩)

공식 이름 : 제목·푸터·상단 부제(긴 풀네임).

상단 짧은 이름 : 상단 바 굵은 글자 (비우면 공식과 같음).

파란 배지 : 왼쪽 네모 안 (비우면 공식 이름 첫 글자).

데이터 보호를 위해 현재 DB를 수동 백업합니다.

백업 파일은 data/backup/ 아래에 날짜·시각이 붙은 이름으로 저장됩니다.

운영 메모

  • 정책 변경 전후로 수동 백업을 권장합니다.
  • 복구 리허설은 운영 복제 DB에서 먼저 확인합니다.
  • 운영 절차 상세는 `docs/1-2_백업_복구_유지보수_가이드.md`를 참고합니다.

운영/상태 안내

마스터 관리 화면은 시간 정책 원칙과 연차 신청 상태 의미를 함께 안내합니다.

  • 연차 신청은 시작/종료 시각 기반으로 1건 스냅샷으로 저장됩니다.
  • 입력 시각은 정책 단위 경계(30/60/120분)만 허용됩니다.
  • 단위는 입력 제어 기준이며, 실제 차감은 선택 구간에서 점심 제외 후 계산됩니다.
  • 하루 총 사용시간은 대시보드/캘린더에서 자동 합산해 표시합니다.

상태값 설명

아래 상태값은 각 연차 신청 건의 처리 상태를 뜻합니다. 타임라인에서 상태를 바꾸면 집계(사용시간/잔여시간)에도 반영됩니다.

  • 결재 대기: 결재 전 상태입니다. 아직 확정되지 않은 신청입니다.
  • 승인됨: 결재가 완료되어 연차 사용으로 확정된 상태입니다.
  • 반려: 승인되지 않은 상태입니다. 사용 시간/잔여 연차 계산에서 제외됩니다.
  • 신청 취소: 기존 신청을 철회·무효 처리한 상태입니다. 사용 시간/잔여 연차 계산에서 제외됩니다.
