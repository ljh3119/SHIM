# SHIM Portable 가이드 (Offline Deployment Guide)

이 문서는 Docker 설치가 불가능하거나 외부망이 완전히 차단된 **폐쇄망 Windows PC** 환경에서 SHIM 시스템을 무설치(Portable) 형태로 구동하기 위한 통합 운영 가이드입니다.

---

## 1. 개요 (Overview)
SHIM Portable은 Python 런타임과 모든 의존성을 단일 패키지로 묶어, 대상 PC에 별도의 소프트웨어 설치 없이 즉시 서비스를 제공할 수 있도록 설계되었습니다.

- **대상 OS**: Windows 10/11 (64-bit)
- **주요 특징**: 제로 디펜던시(Zero-dependency), 데이터 격리 저장, 포트 가변형 실행 지원

---

## 2. 배포 및 전달 (Deployment)
빌드된 산출물을 대상 폐쇄망 PC로 이동하는 단계입니다.

1.  **폴더 복사**: `dist/SHIM_Portable/` 폴더 **전체**를 USB 또는 보안 전달 매체를 통해 대상 PC로 복사합니다.
    - ⚠️ **주의**: `SHIM_Portable.exe` 단독 파일만 복사할 경우 실행되지 않습니다. 반드시 `_internal`, `data` 폴더를 함께 포함해야 합니다.
2.  **권한 확인**: 실행 대상 폴더에 읽기/쓰기 권한이 있는지 확인하십시오. (SQLite DB 기록을 위해 필수)

---

## 3. 실행 및 종료 (Execution)

### 최초 실행 및 구동 (자동화)
1.  **`SHIM_Portable.exe` 실행**: 더블 클릭하여 기동합니다.
2.  **보안설정 (비밀키 입력 및 대화형 설정)**: 
    - 최초 실행 시 보안 서명 및 개인정보 암호화에 사용할 `secret.key` 설정 화면이 콘솔창에 나타납니다.
    - **보안 키 입력 시**: 입력한 키가 `data/secret.key`로 저장되며, DB 내 사원 실명 및 연차 사유 등이 대칭 암호화(`Fernet` 방식)되어 한층 강화된 보안을 제공합니다.
    - **엔터(미입력) 시**: 64자리 무작위 보안키가 자동 기재되며 데이터베이스는 평문 상태로 유지되어, 단독 DB 복사만으로 손쉽게 이전할 수 있는 고이식성 모드로 가동됩니다.
    - 두 번째 기동부터는 키 설정을 건너뛰고 기존 저장된 키를 자동 로드합니다.
3.  **자동 포트 감지**: 기본 `8000` 포트가 사용 중인 경우, `8001`, `8002` 등 비어있는 다음 포트를 탐색 및 자동 할당하여 즉시 실행됩니다. 만약 동일 폴더에서 `SHIM_Portable.exe`가 이미 실행 중인 경우, 기존 인스턴스의 트레이 아이콘에 중복 기동 경고 알림(벌룬 팝업)을 전송한 뒤 새 프로세스는 자동으로 조용히 종료되어 중복 실행을 완벽히 방지합니다.

### 서비스 확인
- **URL**: 터미널 창에 출력된 **`접속 주소`**(예: `http://localhost:8000`)를 웹 브라우저(크롬 등)의 주소창에 직접 입력하여 접속합니다.
- **관리자 계정**: `admin / 0000` (접속 후 즉시 비밀번호 변경 필수)
- **상태 점검**: `http://localhost:포트번호/docs` 접속 시 Swagger 문서가 보이면 정상입니다.

### 서비스 종료
- **종료 방법**: 작업 표시줄 우측 하단의 시스템 트레이 영역에서 SHIM 아이콘을 우클릭하고 **'종료'**를 선택하거나, 패키지 폴더 내의 **`stop_portable.bat`** 파일을 실행하면 백그라운드 서버가 안전하게 완전히 종료됩니다.
- 💡 **주의**: 기동 시 나타나는 콘솔(CMD) 창은 서버 실행을 도와주는 런처 안내 창이므로, 안내 확인 후 창을 닫거나 아무 키나 눌러 종료해도 백그라운드 서버 서비스는 계속 정상 동작합니다.

---

## 4. 운영 및 유지관리 (Maintenance)

### 데이터 백업
- **대상**: `data/shim_internal.db` 파일
- **방법**: 앱 종료 상태에서 해당 파일을 별도 저장소로 복사하여 타임스탬프와 함께 보관하십시오.

### 비상 전환 시나리오 (NAS ↔ PC 데이터 동기화)
서버(NAS) 장애 시 로컬 PC로 운영권을 전환해야 하는 경우 다음 절차를 따르십시오.

#### 시나리오 A: NAS → PC 전환
1.  NAS의 최신 `shim_internal.db` 파일을 확보합니다.
2.  PC의 `SHIM_Portable/data/` 폴더에 해당 파일을 덮어씁니다.
3.  PC에서 `SHIM_Portable.exe`를 실행하여 운영을 재개합니다.

#### 시나리오 B: PC → NAS 복귀
1.  PC에서 `stop_portable.bat`로 서비스를 종료합니다.
2.  PC의 최신 `shim_internal.db` 파일을 NAS의 운영 경로로 복사합니다.
3.  NAS 서버를 재기동하고 데이터 정합성을 확인합니다.

---

## 5. 주의사항 및 정책 (Policies)

- **보안**: `data/secret.key` 파일이 삭제되거나 유출되지 않도록 관리하십시오. 분실 시 기존 쿠키 세션이 모두 무효화됩니다.
- **포트**: 기본값 8000 포트 외에 다른 포트로 즉시 기동하고 싶은 경우, `SHIM_Portable.exe` 실행 시 터미널에서 포트 번호를 직접 입력하거나 명령 프롬프트(CMD)에서 `SHIM_Portable.exe --port 8010`과 같이 직접 포트 인자를 주어 구동할 수도 있습니다.
- **호환성**: 본 패키지는 Windows 64-bit 환경 전용입니다. 타 OS에서는 Docker 배포 방식을 이용하십시오.
- **데이터 무결성**: NAS와 PC를 동시에 운영할 경우 데이터가 분기되어 동기화가 불가능해질 수 있습니다. 반드시 **단일 운영 원칙**을 고수하십시오.
- **회사/팀 배지 색상 식별**: 다중 회사 및 다중 팀 일정의 시각적 혼선을 예방하기 위해, 회사 배지는 엄선된 고대비 웜톤/녹색계열(0~140도)로, 팀 배지는 강렬한 쿨톤 계열(180~340도)로 구분 및 색상 매핑되어 직관적인 식별을 지원합니다.
