# 2026-10-23 개선 작업 검증 결과

## 범위
개발 폴더의 테스트 데이터를 전제로 코드와 검증 스크립트를 수정했습니다. 실행 검사는 별도 가상환경과 임시 DB에서 수행했습니다. 별도 배포 서버에는 접근하거나 변경하지 않았으며 커밋·푸시·배포는 수행하지 않았습니다.

## 반영 내용
- 연차 상세의 사용자 입력을 텍스트로 출력하고 사용자 관리의 인라인 이벤트 인자를 데이터 속성으로 교체했습니다.
- 변경 API의 상태 조회와 저장을 SQLite 쓰기 트랜잭션으로 묶어 승인·취소·반려 및 잔여량 경쟁을 방지했습니다.
- 기존 ADMIN 계정의 역할 강등을 차단했습니다.
- 연도별 할당 누락의 기본값과 명시적 0시간 처리를 통일했습니다.
- 실제 근무시간과 겹치는 점심시간만 차감하고 00:00 시작·24:00 종료 및 전일 선택에 설정값을 반영했습니다.
- 설정 중복 시 변경을 차단하고 대시보드에 백업 복구 호환성 경고를 추가했습니다. 비호환 신규 백업 때문에 기존 호환 백업이 삭제되지 않도록 회전을 건너뜁니다.
- 최초 설정의 키 지문 저장, SQLite 연결 종료, 진행 중인 백업 완료 후 종료를 보완했습니다.
- HTTP 보안 검사 단독 실행을 임시 데이터 폴더로 격리하고 테스트 자식 프로세스 UTF-8을 명시했습니다.

## 남은 운영 확인 범위
- Docker 이미지 재빌드, 포터블 EXE 재패키징, 별도 배포 서버의 실제 DB 업그레이드/복원은 이번 검증에 포함하지 않았습니다.
- 기존 중복 설정 행은 임의로 삭제·병합하지 않았습니다. 운영 적용 시 행별 값을 비교하여 유지할 설정을 결정해야 합니다.
- SQLite API 쓰기는 직렬화됩니다. 동시 쓰기 처리량이 커지는 환경에서는 실제 부하로 잠금 대기와 응답시간을 확인해야 합니다.
- 비호환 백업은 보존되므로 원인을 해결하기 전까지 보존 개수를 초과할 수 있습니다.
