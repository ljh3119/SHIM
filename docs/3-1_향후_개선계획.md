# 향후 개선계획

**범위**: v1.2.0 **이후** 미완료 작업만 둡니다. 끝난 항목은 여기서 **삭제**하고 `docs/2-1_운영_릴리즈_통합_산출물.md`에 증적을 남깁니다.

**Dense UI**: 1차(관리·사용자 핵심 플로우, 로그인·`base`·관리 shell 등)는 **v1.2.0에 반영 완료**(`2-1` 참고). 아래는 그다음 일만 기술합니다.

## 문서 역할(한눈에)

| 구분 | 위치 | 용도 |
|:---|:---|:---|
| 백로그 | **이 문서** | 할 일·우선순위만 편집 |
| 완료 증적 | `docs/2-1_…` | 릴리즈·검증 기록 |
| 구현 기준 | `docs/4-1_…`, `src/templates/`, `src/static/css/app.css` | 동작·토큰·화면의 근거 |
| 시안·디렉팅(선택) | `design/ui-handoff/` | P2 UI·**새 화면** 레이아웃 합의 시 HTML 참고(`README.md`, `directing/admin-dashboard-design-direction.md`). **과제 목록은 두지 않음** |
| 작업 규칙 | `docs/3-2_…` | 인수인계·금지 사항 |

**워크플로**: 새 아이디어 → `3-1` 한 줄 추가 → 구현 → `3-1`에서 제거 + `2-1` 보강. 시안이 필요하면 아카이브에 샘플만 추가하고, 백로그 문장은 `3-1`에만 둡니다.

## 작업 원칙

- 한 번에 하나의 기능 단위만 진행합니다.
- 기존 URL, 응답 형식, DB 엔진, 주요 화면 흐름은 유지합니다.
- 결재와 무관한 UX 전면 개편, 대규모 폴더 구조 변경, 프레임워크 전환은 하지 않습니다.
- 작업 전 `docs/3-2_AI_인수인계_가이드.md`를 확인합니다.
- 검증·릴리즈가 끝나면 `docs/2-1_운영_릴리즈_통합_산출물.md`를 갱신합니다.

## P1: 다음 개발 후보

### P1-1. 운영 인수 리허설

- **목표**: 운영용 `SHIM_SECRET_KEY`, 기본 관리자 비밀번호 변경, 백업·`.bak` 복구, Docker 재기동을 한 절차로 연습·확인합니다.
- **완료 기준**: 담당자가 동일 절차를 반복 가능. 복구 후 로그인·신청 조회·관리 캘린더 정상. (비밀번호·시크릿 **본문은 문서에 쓰지 않음**.)

### P1-2. 운영 인수 잔여 항목

- **목표**: 필수 보안 항목을 끝내고 `2-1`에 증적만 남깁니다.
- **완료 기준**: `.env`에 운영용 `SHIM_SECRET_KEY` 설정(값 미기록), 기본 관리자 최초 비밀번호 변경 확인, `2-1` 이관.
