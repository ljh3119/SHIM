## 작업 원칙

- 한 번에 하나의 기능 단위만 진행합니다.
- 기존 URL, 응답 형식, DB 엔진, 주요 화면 흐름은 유지합니다.
- 결재와 무관한 UX 전면 개편, 대규모 폴더 구조 변경, 프레임워크 전환은 하지 않습니다.
- 작업 전 `docs/3-2_AI_인수인계_가이드.md`를 확인합니다.
- 검증·릴리즈가 끝나면 `docs/2-1_운영_릴리즈_통합_산출물.md`를 갱신합니다.

## P1: 우선순위 개선 항목

### P1-1. 감사 로그 조회 UI 보강
- **목표**: 관리자 마스터 화면의 감사 로그 섹션 가독성을 높이고, 필터링(수행자, 액션 등) 기능을 추가합니다.
- **완료 기준**: 마스터 화면에서 최근 100개 이상의 로그를 쾌적하게 조회 가능.

### P1-2. 사원 관리 작업 버튼 정리
- **목표**: 사원 목록의 '초기화/상태변경/삭제' 버튼들이 공간을 많이 차지하므로, 드롭다운 또는 아이콘 버튼으로 정리하여 가로 공간을 확보합니다.
- **완료 기준**: 좁은 화면에서도 사원 목록 테이블이 깨지지 않고 조작 가능.
