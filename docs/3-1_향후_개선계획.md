# 향후 개선계획 (Product Roadmap)

이 문서는 SHIM 프로젝트의 중장기 발전 방향과 차기 버전의 백로그를 관리합니다. 폐쇄망 구동 환경의 특성 및 슬림한 포터블 배포라는 철학에 맞추어 우선순위와 기술 방향성을 조정했습니다.

---

## 🎯 1. 개발 및 운영 원칙
- **Minimalism (초경량성)**: 외부 환경이나 추가 의존성 없이 장기 구동이 가능하도록 외부 종속성을 철저히 제한합니다.
- **Lightweight Portable (슬림한 배포)**: 포터블 바이너리(`SHIM_Portable.exe`)의 기동 속도와 런타임 성능을 최적화하기 위해, 구동에 불필요한 서드파티 라이브러리 및 임포트 의존성을 전면 배제하여 순수하게 유지합니다.
- **Verification**: 모든 기능 추가 시 `tools/scripts` 내 검증 시나리오를 동기화하여 안정성을 보장합니다.
- **Consistency**: 기존의 시간 정책(30/60/120분 단위)과 Dense UI 디자인 시스템의 고유 정체성을 준수합니다.

---

## 🚀 2. 주요 개선 과제 (Backlog)

### [P1] 정식 출시 기준 정비 및 마이그레이션 베이스라인화
- **정식 출시 시점의 마이그레이션 스쿼시(Squash) 및 베이스라인화**:
  - 정식 배포(v1.6.0 또는 정식 서비스용 버전) 릴리즈 시, 기존 테스트/개발 단계에서 적용되었던 점진적 마이그레이션 스텝들(`v1.4.0`, `v1.5.0`, `v1.5.6` 등)을 SQLAlchemy 기본 스키마 정의(`models.Base.metadata.create_all`)로 전면 통합합니다.
  - 정식 버전 이후 실운영 중에 발생하는 스키마 변경 사항만 신규 마이그레이션으로 정의하여 데이터베이스 관리 복잡도를 예방합니다.

### [P2] 시스템 운영성 개선 및 기능 고도화
- **포터블/컨테이너 구동 시 브라우저 자동 오픈 제어 옵션**:
  - `SHIM_Portable.exe` 기동 시 Headless 서버 환경이나 자동 팝업이 불필요한 배포 환경에 대응하기 위해, `SHIM_NO_BROWSER=true` 환경 변수를 추가하여 브라우저 자동 활성화 여부를 선택적으로 끌 수 있게 조절합니다.
- **전사 연차 통합 다운로드 기능 고도화**:
  - 현재 개별 신청 목록(타임라인)만 내보내던 기능을 발전시켜, 사원의 연차 배정 및 잔여 현황과 세부 신청 내역을 단일 엑셀 파일(다중 시트 구성: Sheet 1 - 사원별 연차 현황 요약, Sheet 2 - 상세 신청 내역 타임라인)로 통합 출력하여 하나의 엑셀에서 확인 및 대조할 수 있도록 고도화합니다.

## ⏳ 3. 장기 보류 및 재검토 과제 (P3)

### [P3] 기획 검토 및 철학적 조율 필요 과제
- **장기 적재 감사 로그의 아카이브 및 정리(Cleanup) 기능**:
  - 장기 운용 시 SQLite DB 파일의 비대화를 방지하고 최적 성능을 유지할 수 있도록, 1년 이상 경과한 감사 로그를 XLSX/JSON 파일로 아카이브 백업 후 DB에서 삭제하는 배치 기능을 낮은 우선순위로 검토합니다.
- **임시/대체 공휴일 일괄 업로드 기능 검토**:
  - 오프라인/폐쇄망 내에서 임시/대체공휴일이 동적 지정될 때, 관리자의 수동 입력 편의를 위해 공휴일 일괄 업로드 형식을 검토하되, 공휴일 변동 빈도가 매우 낮음을 고려하여 구현 우선순위를 보류합니다.
- **감사 로그 데이터 구조화(JSON화) 여부**:
  - "가볍고 오래 켜둘 수 있는 초경량 시스템"이라는 SHIM의 핵심 철학을 고려할 때, JSON 포맷 도입이 SQLite I/O에 미칠 영향을 재검토하여 텍스트 기반 및 한글 매핑 헬퍼를 유지할지 결정합니다.
- **사원 비활성화 시 미래 연차 처리**:
  - 사원 비활성화 시 미래 연차의 자동 반려가 실무 예외 프로세스(예: 복직 등)와 충돌할 소지가 있으므로 구체적인 기획 검토 완료 후 진행 여부를 결정합니다.
- **실시간 웹소켓 알림**:
  - 일반적인 사용 환경 및 폐쇄망에서는 필요성이 낮으므로, 향후 외부망 연동 등 대규모 업데이트 로드맵이 그려지는 시점까지 검토를 보류합니다.
