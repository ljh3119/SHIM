# 향후 개선계획 (Product Roadmap)

이 문서는 SHIM 프로젝트의 중장기 발전 방향과 차기 버전의 백로그를 관리합니다. 

---

## 🎯 1. 개발 및 운영 원칙
- **Minimalism**: 폐쇄망 환경의 특수성을 고려하여 외부 의존성을 최소화합니다.
- **Consistency**: 기존의 시간 정책(30/60/120분 단위)과 Dense UI 디자인 시스템을 유지합니다.
- **Verification**: 모든 기능 추가 시 `tools/scripts` 내 검증 시나리오를 동기화합니다.

---

## 🚀 2. 주요 개선 항목 (Backlog)

### [P1] 우선순위 핵심 과제
| ID | 과제명 | 목표 | 완료 기준 |
|:--- |:--- |:--- |:--- |
| **P1-1** | **감사 로그 조회 UI 보강** | 관리자 마스터 화면의 로그 가독성 및 필터링 강화 | 수행자, 액션, 기간별 검색 지원 |
| **P1-2** | **사원 관리 UX 정리** | 사원 목록 테이블의 작업 버튼 최적화 (가로 공간 확보) | 드롭다운 또는 아이콘 버튼 도입 |
| **P1-3** | **타임라인 페이징 도입** | 대량 데이터(연 1만 건+) 조회 시 브라우저 부하 방지 | 서버 측 LIMIT/OFFSET 적용 (기본 50건) |
| **P1-4** | **운영 마감 프로세스 설계** | 연도별 데이터 확정 및 수정 방지 기능 | 마감 버튼 클릭 시 해당 연도 신청 수정 불가 |

### [P2] 편의 및 확장 과제
- **근태 항목 확장**: 연차 외 '출장(연차 미소모)', '공가(유급 휴가지만 개인 연차 미소모)' 등 신규 유형 지원
    - 데이터베이스 `leave_type` 필드 확장 및 연차 차감 로직 예외 처리 구현
    - 팀 캘린더 내 유형별 색상 테마(예: 출장-초록, 공가-보라) 및 한국어 라벨 적용
- **통계 리포트**: 전사/팀별 연차 사용 현황 엑셀 다운로드 기능 (관리자용)
- **알림 강화**: 외부망 차단 환경 내에서 브라우저 Web Push 또는 자체 대시보드 알림 위젯
- **접근성 개선**: Dense UI 내 고대비 모드 및 키보드 내비게이션 보강

## 🏗️ 3. 기술 부채 및 아키텍처 과제
- **마이그레이션 도구**: Alembic 도입을 통한 정식 데이터베이스 스키마 버전 관리
- **테스트 커버리지**: 비즈니스 로직(연차 계산)에 대한 단위 테스트 강화
- **포터블 최적화**: PyInstaller 빌드 속도 개선 및 실행 바이너리 용량 최적화
