# SHIM 문서 인덱스

문서가 분산되어 보이지 않도록, 현재 유지되는 산출물만 정리한 인덱스입니다. 이 파일은 목차 역할만 하며, 상세 내용은 각 담당 문서에서 관리합니다.

버전·최신 릴리즈 표기는 **저장소 루트 `README.md`**(대외용 요약) 또는 **`package.json`의 `version`**을 기준으로 합니다. 완료된 릴리즈 증적·검증 요약은 `docs/2-1_운영_릴리즈_통합_산출물.md`를 봅니다.

권장 읽기 순서:

1. 운영/실행: `docs/1-1_초심자_구동_가이드.md` -> `docs/1-2_백업_복구_유지보수_가이드.md`
2. 운영 릴리즈 실행: `docs/1-3_운영_릴리즈_실행_체크리스트.md`
3. 현재 릴리스 확인: `docs/2-1_운영_릴리즈_통합_산출물.md`
4. 다음 개발 작업: `docs/3-1_향후_개선계획.md` -> `docs/3-2_AI_인수인계_가이드.md`

## 현재 기준

- 상세 릴리즈 증적/검증 결과: `docs/2-1_운영_릴리즈_통합_산출물.md`
- 앞으로 할 일: `docs/3-1_향후_개선계획.md`

## 운영/사용 문서

- `docs/1-1_초심자_구동_가이드.md`
  - 신규 인수자/운영자가 실행까지 따라가는 기본 가이드
- `docs/1-2_백업_복구_유지보수_가이드.md`
  - 백업, 복구, 배포, 장애 대응 절차
- `docs/2-1_운영_릴리즈_통합_산출물.md`
  - 완료된 릴리즈 증적, 검증 결과, 운영 인수 체크리스트
- `docs/1-3_운영_릴리즈_실행_체크리스트.md`
  - 운영 담당자용 1페이지 릴리즈 실행 체크리스트
- `portable/README_PORTABLE.md`
  - Docker 불가 환경에서 무설치 실행 가이드

## 기획/정리 문서

- `docs/4-1_SHIM_프로젝트_설계서.md`
  - 시스템 전반 설계/구성/변경 이력
- `docs/3-1_향후_개선계획.md`
  - 앞으로 할 작업만 관리하는 개선계획
- `docs/3-2_AI_인수인계_가이드.md`
  - 다른 AI 또는 개발자가 이어받을 때 지켜야 할 기준
- `docs/1-4_작업_로그.md`
  - 릴리즈 증적에 넣지 않는 내부 작업 메모
- `design/ui-handoff/` (`README.md`)
  - Dense **정적 시안·디렉팅**(참고, 런타임 미사용). 백로그는 `3-1`, 구현은 `src/templates`·`app.css`·`docs/4-1`

## 문서 유지 기준

- 완료된 작업은 `docs/2-1_운영_릴리즈_통합_산출물.md`에만 기록한다.
- 앞으로 할 일은 `docs/3-1_향후_개선계획.md`에만 기록한다.
- AI 작업 규칙은 `docs/3-2_AI_인수인계_가이드.md`에만 기록한다.
- 실행 절차는 `docs/1-1_초심자_구동_가이드.md`, 운영/복구 절차는 `docs/1-2_백업_복구_유지보수_가이드.md`, 릴리즈 당일 체크는 `docs/1-3_운영_릴리즈_실행_체크리스트.md`에 기록한다.
- 구현 기준은 `docs/4-1_SHIM_프로젝트_설계서.md`에 기록하고, 단순 변경 이력은 중복 기록하지 않는다.
- 현재 운영 정책과 맞지 않는 과거 계획 문서는 필요한 내용만 흡수하고 제거한다.
- 새 산출물이 생기면 이 파일을 먼저 갱신한다.
