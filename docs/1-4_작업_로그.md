# 시스템 작업 로그 (System Internal Logs)

이 문서는 공식 릴리즈 증적에 포함되지 않는 개발 단계의 내부 기술 메모 및 작업 이력을 기록합니다. 주요 기능의 아키텍처적 결정이나 문제 해결 과정 등을 보관하여 향후 유지보수의 참고 자료로 활용합니다.

> [!NOTE]
> **로그 작성 규칙**: 이 문서는 작업이 추가될 때마다 최신 로그가 맨 위에 위치하도록 **역연대순(최신순)**으로 작성합니다. 수정 및 조회 시 파일 앞부분만 다루므로 에이전트와 사용자 모두의 토큰 소모를 최소화합니다.

### v1.8.9 SQLite 동시성 트랜잭션 동기화 풀백 방식 및 NAS 환경 데이터 무결성 보완
- **SQLite synchronous=FULL 격상**:
  - Btrfs 파일 시스템이나 NAS 디스크 쓰기 버퍼에서 비동기 I/O 지연으로 인한 SQLite WAL 무결성 깨짐 및 데이터 파일 유실 현상을 방지하기 위해, 데이터베이스 연결 프라그마 정책을 `PRAGMA synchronous=NORMAL;`에서 `PRAGMA synchronous=FULL;`로 한층 강화하여 트랜잭션 완료 시 디스크 물리 플러시를 완전히 보장했습니다.
- **Lifespan 중단 시 수동 체크포인트 로직 제거**:
  - 기존 FastAPI 서버 중단 시 Lifespan 핸들러에서 명시적으로 호출하던 `PRAGMA wal_checkpoint(TRUNCATE);` 구문이 활성 커넥션 풀과 엉켜 교착 상태(Deadlock) 및 I/O 지연을 초래하던 버그를 제거했습니다.
  - 별도 신규 세션 생성 대신, SQLAlchemy 커넥션 풀을 순수 해제(`engine.dispose()`)하는 것만으로 SQLite 자체 드라이버가 종료 전 자동으로 WAL 트랜잭션을 안전히 병합하고 관련 파일들을 지우도록 종료 시퀀스를 리팩토링했습니다.
