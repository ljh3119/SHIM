### 성능 최적화 및 구동 방어 시스템 구축
- **Windows 런처 Mutex 기반 중복 실행 차단 구현**:
  - `shim_portable.py` 런처 기동 시 실행 파일 경로 MD5 해시 기반 전역 Mutex(`SHIM_Portable_Mutex_<Hash>`)를 선점하여 동일 경로 마스터 프로세스의 중복 기동을 물리적으로 차단했습니다.
  - 기존 마스터 윈도우(`SHIMTrayClass`)가 존재할 경우 `PostMessageW`를 통해 `ID_TRAY_TRIGGER_BALLOON` 이벤트를 날린 뒤 조용히 종료(`exit code 0`)되도록 구조를 설계했습니다. 수신받은 기존 트레이는 사용자에게 중복 기동 경고 벌룬 알림을 전송합니다.
  - 마스터가 self-fork하여 기동하는 자식 Uvicorn 프로세스(`--uvicorn-worker`)에 대해서는 뮤텍스 중복 체크를 우회(Pass)하도록 예외 예방 코드를 적용했습니다.
- **엑셀 다중 시트 다운로드 메모리 스트리밍 최적화 (WriteOnlyWorkbook)**:
  - `/admin/leave/timeline/export` API에서 수만 건의 엑셀 출력 시 메모리가 폭발하던 DOM 적재 문제를 극복하기 위해 `Workbook(write_only=True)` 스트리밍 모드를 도입했습니다.
  - 스트리밍 제약 조건에 부합하도록 첫 번째 시트("연차 현황 요약")와 두 번째 시트("상세 신청 내역")를 순차 생성해 행 단위로 데이터를 즉시 플러시하여 피크 메모리를 10MB 상수로 최적화했습니다.
