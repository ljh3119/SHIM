## 📅 2026-05-17
### v1.4.0 관리자 사용성 및 안정성 강화 (P1 과제 완료)
- **감사 로그(Audit Logs) 분리 및 고도화**:
  - 기존 마스터 화면 종속성을 탈피하여 전용 페이지(`/admin/audit`) 신설.
  - 대량 데이터 조회를 위한 서버 측 페이징(LIMIT/OFFSET 50건 단위) 도입.
  - 가독성 극대화를 위한 액션 및 대상 정보 100% 한글화 처리 (예: `User:admin` -> `사원:admin`).
  - Python `openpyxl`을 활용한 필터링된 로그 전체 엑셀 다운로드 기능 구현.
  - 템플릿 내 Python 표준 함수(`min`, `max`) 미등록으로 인한 Internal Server Error 해결.
- **사원 관리 UI 안정화**:
  - 가로 스크롤 이슈를 유발하던 드롭다운 메뉴를 제거하고 콤팩트 아이콘 버튼 4종으로 대체.
- **연차 삭제 로직(Race Condition) 픽스**:
  - 연차 강제 삭제 시 네트워크 오류가 발생하던 원인 분석 (DB 삭제가 로그 기록 전 연관 객체 참조를 끊어버리는 문제).
  - 로컬 변수 사전 할당 방식 및 `repro_delete_issue.py`를 통한 단위 테스트로 완벽 해결.
- **릴리즈 파이프라인**:
  - `verify_version_sync.ps1` 검증을 포함한 전역 버전(`1.4.0`) 업데이트 및 Docker/포터블 빌드 산출물 생성 완료.
