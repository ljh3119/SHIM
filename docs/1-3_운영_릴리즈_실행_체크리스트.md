# 운영 릴리즈 1페이지 체크리스트

이 문서는 운영 담당자가 릴리즈 시 바로 체크할 수 있는 실무용 요약본입니다.

## A. 릴리즈 준비

- [ ] 프로젝트 루트 폴더 진입
- [ ] 신규 버전 확정 (예: `1.3.2`)
- [ ] Docker Desktop 실행 상태 확인

## B. 버전 반영 + 빌드 + 기본 검증

- [ ] 아래 명령 1회 실행

```powershell
.\tools\scripts\release.ps1 -Version 1.3.2 -BuildImage -RunChecks
```

- [ ] 오류 메시지 없이 완료 확인(`-RunChecks`에는 `compileall`, CSS 빌드, compose 검증, **`verify_version_sync.ps1`(코드·README·포터블 README 버전 일치)** 가 포함됨)
- [ ] 생성 이미지 태그 확인: `shim:1.3.2`, `shim:latest`
- [ ] (선택) `-RunChecks` 없이 버전만 반영했다면, 또는 재확인이 필요하면 아래로 문서·산출물 문자열 일치 여부만 점검

```powershell
.\tools\scripts\verify_version_sync.ps1
```

## C. 로컬 실행 점검

- [ ] 운영 모드 컨테이너 기동

```powershell
.\tools\scripts\docker.ps1 up-prod
```

- [ ] 점검 URL 접속 확인
  - [ ] `http://localhost:8000/`
  - [ ] `http://localhost:8000/docs`
  - [ ] `http://localhost:8000/static/css/tailwind.css`
- [ ] 관리자 로그인 후 대시보드 진입 확인

## D. 폐쇄망 반입 산출물 준비

### D-1. Docker 반입본

- [ ] 버전 태그 이미지 내보내기

```powershell
docker save -o shim_1.3.2.tar shim:1.3.2
```

- [ ] 전달 파일명/버전 일치 확인 (`1.3.2`)

### D-2. Portable 반입본

- [ ] 포터블 빌드 실행

```powershell
powershell -ExecutionPolicy Bypass -File .\portable\build_portable.ps1
```

- [ ] 포터블 실행 점검(예: 8765 포트)

```powershell
.\artifacts\dist\SHIM_Portable\run_portable.bat 8765
```

- [ ] 응답 점검 후 종료
  - [ ] 최초 실행 시 `SHIM_SECRET_KEY` 입력 및 `data/secret.key` 생성 확인
  - [ ] `http://localhost:8765/`
  - [ ] `http://localhost:8765/docs`
  - [ ] `http://localhost:8765/static/css/tailwind.css`
  - [ ] `http://localhost:8765/favicon.ico`
  - [ ] `.\artifacts\dist\SHIM_Portable\stop_portable.bat`
- [ ] 전달 폴더: `artifacts/dist/SHIM_Portable`
- [ ] 폴더 통째 복사 확인 (`.exe` 단독 전달 금지)
- [ ] 포함 파일 확인
  - [ ] `SHIM_Portable.exe`
  - [ ] `run_portable.bat`
  - [ ] `stop_portable.bat`
  - [ ] `_internal` 폴더
  - [ ] `data` 폴더

## E. 운영 인수 전 필수 보안 확인

- [ ] `.env`에 운영용 `SHIM_SECRET_KEY` 적용
- [ ] 기본 관리자 비밀번호 변경 확인 (`admin / 0000` 유지 금지)

## F. 장애 시 즉시 확인

- [ ] 포트 충돌 여부 확인 (`8000`)
- [ ] 컨테이너 로그 확인

```powershell
.\tools\scripts\docker.ps1 logs
```

- [ ] 필요 시 재기동

```powershell
.\tools\scripts\docker.ps1 restart
```
