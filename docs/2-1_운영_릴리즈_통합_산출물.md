### v1.5.14 (2026-05-29) - 일반 사용자 연차 신청 취소 기능 추가 및 캘린더/배지 UX 밀도 극대화
- **일반 사용자 연차 직접 취소 기능 구현**:
  - 기존에는 유저가 본인이 신청한 연차를 직접 취소할 수 없었으나, 기안자가 본인이 올린 **결재 대기(PENDING)** 상태의 연차에 대해 직접 신청을 취소할 수 있도록 `POST /api/user/leave/cancel/{leave_id}` API를 구현했습니다.

  - 신청 취소 시 `apply_leave_status_transition`을 호출하여 상태를 `CANCELED`로 안전하게 전이하며, `AuditLogs` 테이블에 `CANCEL_LEAVE` 사유와 함께 감사 로그가 누락 없이 기록됩니다.
- **유저 연차 신청 내역 화면 취소 UI 적용**:

  - 취소 버튼 클릭 시 실행될 JavaScript 함수 `cancelLeave(leaveId)`를 추가하여 Fetch API 기반으로 본인 취소 API를 실시간 호출하도록 연동을 마쳤습니다.
- **관리자 타임라인 UI/UX 개선 (행위가 완료된 건 드롭다운 제거)**:
  - 기존에는 관리자가 연차 타임라인(`admin_leaves_timeline.html`)에서 모든 연차의 상태를 드롭다운으로 변경할 수 있었으나, 이미 승인(APPROVED), 반려(REJECTED), 취소(CANCELED)가 완료된 건은 어차피 상태 변경이 불가능함에도 드롭다운이 노출되어 어색함을 유발했습니다.
  - 이를 개선하여 오직 결재 대기(PENDING) 상태인 연차 건에 대해서만 상태 변경 드롭다운을 노출하고, 처리가 완료된 건은 고정된 텍스트 배지(Badge)로 표시하도록 UI를 고도화했습니다. (반려 사유 표시는 기존 스타일 유지)
