# 초심자 구동 가이드 (Quick Start Guide)

이 문서는 SHIM 프로젝트를 처음 접하는 사용자가 **10분 이내에 시스템을 성공적으로 구동**할 수 있도록 돕는 실무 가이드입니다.

---

## 🛠️ 환경별 실행 로드맵

### 1. 로컬 개발 환경 (Local / venv)
가장 빠르게 코드를 실행하고 UI를 확인하고 싶을 때 사용합니다.

1.  **가상환경 활성화**:
    ```powershell
    # Windows PowerShell 기준
    python -m venv .venv
    .venv\Scripts\Activate.ps1
    ```
2.  **의존성 설치**:
    ```powershell
    pip install -r requirements.txt
    npm install
    ```
3.  **서버 실행**:
    ```powershell
    # Tailwind 빌드와 Uvicorn 서버를 동시에 실행합니다.
    npm run dev
    ```
4.  **접속**: `http://localhost:8000` (관리자 계정: `admin / 0000`)

### 2. 운영 환경 (Production / Docker)
실제 서비스를 운영하거나 컨테이너 환경에서 실행할 때 사용합니다.

1.  **보안 설정**: `infra/docker/.env.example`을 루트의 `.env`로 복사하고 `SHIM_SECRET_KEY`를 설정합니다. (상세 내용은 [백업/유지보수 가이드](1-2_백업_복구_유지보수_가이드.md) 참조)
2.  **이미지 빌드**:
    ```powershell
    docker build -f infra/docker/Dockerfile -t shim:1.5.1 -t shim:latest .
    ```
3.  **컨테이너 가동**:
    ```powershell
    docker compose -f infra/docker/docker-compose.yml up -d
    ```

### 3. 폐쇄망 환경 (Portable / No-install)
인터넷이나 Docker 설치가 불가능한 독립형 PC에서 실행할 때 사용합니다.

- **가이드**: `portable/README_PORTABLE.md` 참조
- **핵심**: 빌드된 `artifacts/dist/SHIM_Portable` 폴더를 복사한 후 `run_portable.bat`을 실행합니다.

## 🔍 문제 해결 (Troubleshooting)

| 현상 | 원인 및 해결 방법 |
|:--- |:--- |
| **8000 포트 충돌** | 다른 프로그램이 포트를 사용 중입니다. `npm run dev` 대신 `python -m uvicorn src.app.main:app --port 8080 --reload`와 같이 직접 실행하세요. |
| **접속 불가 (404/500)** | 서버 로그를 확인하세요. Docker의 경우 `docker compose logs -f` 명령어로 실시간 확인이 가능합니다. |
| **데이터 초기화 안 됨** | `var/data/shim_internal.db` 파일 존재 여부와 권한을 확인하세요. |
| **CSS 미적용** | `npm run dev`가 정상 실행 중인지, 또는 `src/static/css/tailwind.css` 파일이 생성되었는지 확인하세요. |
