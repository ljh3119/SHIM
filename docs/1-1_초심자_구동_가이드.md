# 초심자 구동 가이드

처음 받은 사람이 **10분 내 실행 성공**하는 것을 목표로 한 최소 가이드입니다.

## 1) 가장 빠른 실행 (권장)

프로젝트 루트에서:

```powershell
pip install -r requirements.txt
npm install
npm run dev
```

접속:

- `http://localhost:8000`
- 관리자 기본 계정: `admin / 0000`
- 참고: `npm run dev`는 기본 포트 `8000`으로 고정 실행됩니다.

## 2) Docker로 실행

운영 경로는 먼저 이미지를 만든 뒤 compose로 실행합니다.

```powershell
$env:SHIM_SECRET_KEY = "운영용_긴_랜덤_문자열"
docker build -f infra/docker/Dockerfile -t shim:1.2.0 -t shim:latest .
docker compose -f infra/docker/docker-compose.yml up -d
```

중지:

```powershell
docker compose -f infra/docker/docker-compose.yml down
```

## 3) 포터블 실행(폐쇄망/무설치)

- 가이드: `portable/README_PORTABLE.md`
- 핵심: `artifacts/dist/SHIM_Portable` 폴더를 통째로 복사 후 `run_portable.bat` 실행

## 4) 문제 발생 시 빠른 확인

- 포트 충돌:
  - 권장 실행(`npm run dev`)은 `8000` 고정입니다.
  - 다른 포트를 쓰려면 아래처럼 직접 실행하세요.
  ```powershell
  python -m uvicorn src.app.main:app --host 0.0.0.0 --port 8080 --reload
  ```
- 접속 불가: 서버 로그/컨테이너 로그 확인
- 데이터 확인: `var/data/shim_internal.db` 존재 여부 확인
- Docker 로그 확인:
  ```powershell
  docker compose -f infra/docker/docker-compose.yml logs --tail=80
  ```

## 6) 릴리즈 버전 업데이트(권장)

버전 변경 시 수동 편집 대신 아래 명령으로 동기화합니다.

```powershell
.\tools\scripts\release.ps1 -Version 1.2.0 -BuildImage -RunChecks
```

설명:

- `-Version`: `package.json`, `src/app/main.py`, `src/templates/base.html`, `infra/docker/docker-compose*.yml` 버전을 동기화
- `-BuildImage`: `shim:1.2.0` + `shim:latest` 이미지 빌드
- `-RunChecks`: `compileall`, CSS 빌드, compose 설정 검증 실행
