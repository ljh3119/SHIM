마스터 데이터 관리

연차 신청에 쓰이는 시간대와 결재·백업 같은 시스템 설정을 한곳에서 다룹니다.

업무 규칙 설정

승인 워크플로우 — 현재: 켜짐 (결재 필요)

꺼짐: 사원이 신청하면 바로 «승인됨»으로 기록됩니다.
켜짐: 신규 신청은 «결재 대기»로 들어가며, 관리자가 타임라인에서 승인·반려·취소 처리합니다.

시간 단위 / 업무시간 / 점심시간 정책

1) 시간 단위

입력 제어용 최소 단위입니다. 실제 차감은 선택 구간에서 점심시간 제외 후 계산됩니다.

2) 업무시간 범위

시작
종료

신청 화면은 이 구간만 표시됩니다.

3) 점심시간 제외 (선택)

시작
종료

각 값은 차감시간 계산에서 자동 제외됩니다.

시스템 운영 작업

데이터 보호를 위해 현재 DB를 수동 백업합니다.

백업 파일은 data/backup/ 아래에 날짜·시각이 붙은 이름으로 저장됩니다.

운영 메모
  • 정책 변경 전후로 수동 백업을 권장합니다.
  • 복구 리허설은 운영 복제 DB에서 먼저 확인합니다.
  • 운영 절차 상세는 docs/1-2_백업_복구_유지보수_가이드.md를 참고합니다.

운영 / 상태 안내

마스터 관리 화면은 시간 정책 원칙과 연차 신청 상태 의미를 함께 안내합니다.

  • 연차 신청은 시작/종료 시각 기반으로 1건 스냅샷으로 저장됩니다.
  • 입력 시각은 정책 단위 경계(30/60/120분)만 허용됩니다.
  • 결재 대기 · 승인됨 · 반려 · 신청 취소 상태는 타임라인과 집계에 반영됩니다.
