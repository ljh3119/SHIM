현행 프로젝트 대시보드

월별 캘린더와 12달 전체 연간 캘린더를 탭으로 전환하는 구조. 복잡하고 무거운 페이지(1138줄)와 낮은 정보 밀도가 특징인 기존 레이아웃.

✓ 개인의 1년 일정을 통째로 스크롤하여 조회 가능
✗ 연간 뷰 진입 시 스크롤 폭발, 팀 일정을 보려면 페이지 이동 필수
A안: 월별 단일화
난이도: ★
철학 부합: ★★☆

대시보드 월별 캘린더 단일화

기존 대시보드 내의 정보 밀도가 낮고 활용성이 떨어지는 '연간 뷰' 탭을 제거하고, '월별 뷰' 캘린더만 깔끔하게 남기는 최단기 안정성 확보안.

✓ 최소한의 변경으로 즉각적인 버그/화면 복잡도 해소
✗ 여전히 "오늘 누가 쉬는가"를 확인하기 위해 메뉴 이동 필요
★ 추천 시안
B안: 팀 통합 신청
난이도: ★★
철학 부합: ★★★

팀 캘린더 통합 연차 신청

프로젝트 캘린더(타임라인/캘린더 뷰) 상에서 나(★)의 행 빈 날짜 셀을 직접 클릭하여 연차를 즉시 신청하는 동선 일체화 모델.

✓ 팀원의 이탈/중첩 여부를 보면서 즉각 신청 가능 (동선 최소화)
✗ 프로젝트 캘린더 기능이 비활성화된 소규모 팀에서는 대시보드 폼 필요
C안: 하이브리드 3단 탭
난이도: ★★★
철학 부합: ★★★

대시보드 하이브리드 3단 탭 통합

대시보드 내부를 '나의 현황', '팀 일정', '연차 신청' 탭으로 완전히 쪼개어, 페이지 이동 없이 하나의 홈에서 모든 정보가 전환되는 올인원 형태.

✓ 사이드바 3개 메뉴의 역할을 단 하나의 페이지에서 유기적으로 조작
✗ 초기 페이지 로딩 데이터 증가 및 프론트/백엔드 로직 통합 복잡성
D안: 사이드 패널 분할
난이도: ★★
철학 부합: ★★★

좌측 신청 + 우측 캘린더 분할 뷰

팀/프로젝트 캘린더를 메인에 배치하고, 좌측에 "나의 연차 현황 + 간편 신청 폼 + 최근 신청" 패널을 고정하여 정보를 완전하게 대칭시키는 구조.

✓ 팀 캘린더에서 날짜 확인 후 좌측 패널에서 즉시 신청 입력 가능
✗ PC 전용 Dense UI 에서는 정교한 그리드 가로폭 설계 요구됨
E안: 대시보드 허브화
난이도: ★
철학 부합: ★★☆

대시보드 허브화 (캘린더 제거)

대시보드에서 캘린더를 아예 들어내고, 통계 + 퀵액션 링크 카드 + 최근 5건 신청 목록 위주의 콤팩트 허브(Hub)로 개편하는 형태.

✓ 대시보드 성능 향상, 코드 용량이 대폭 축소되어 유지보수성 최우수
✗ 달력 모양이 없으므로 일정 예약형 UI를 좋아하는 사용자의 불만 유발 가능
F안: 팀 캘린더 기본 홈
난이도: ★★
철학 부합: ★★★

팀 캘린더를 메인 기본 홈으로

로그인 후 첫 랜딩 페이지 자체를 팀 캘린더로 변경하고, 상단에 미니 연차 카드 요약과 하단에 신청 내역 아코디언을 배치하여 캘린더 중심 시스템으로 개편.

✓ 시스템 철학인 "현장 연차 가시화 도구"에 완벽히 정렬됨
✗ 대시보드와 팀 캘린더 화면의 구분이 다소 모호해짐
★ 최종 조합안
G안: 최적 조합안
난이도: ★★★
철학 부합: ★★★

D안(골격) + B안(인터랙션) + E안(모바일)

PC/태블릿에서는 2컬럼 레이아웃에 직접 셀 클릭 신청 및 대기 셀 결재/취소를 적용하고, 모바일에서는 달력 대신 통계/퀵액션과 날짜이동형 부재자 리스트를 제공하는 최적 조합안.

✓ PC 대화면 정보 밀도 및 동선 최소화 + 모바일 특화 반응형 UX 극대화
✓ 모바일 날짜 이동(< 오늘 >) 기능 및 철저한 상태 동기화 처리
