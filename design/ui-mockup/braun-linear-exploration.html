SHIM C안(Braun × Linear) 정제 및 네 가지 구조 변주

오프라인 정적 프로토타입

기존 비교안에서 A, B, D를 제외하고 C안의 따뜻한 계기판 표면, 절제된 모서리 반경(2px~6px), 기존 SHIM 파란 강조색을 공통 체계로 고정한 뒤 레이아웃과 정보 밀도, 업무 흐름을 달리한 네 가지 앱 화면(C 기준안, C1, C2, C3)을 구성했습니다.

가상 데모 데이터 안내: 화면에 표시된 성명(김지수, 박준호 등), 소속 법인 및 팀, 연차 시간, 결재 건수는 모두 시안 비교용 가상 데이터이며 실제 데이터베이스나 백엔드 서버와 연결되지 않습니다.

네 가지 시안의 레이아웃과 업무 흐름 차이

색상만 바꾼 스킨이 아니라 내비게이션 셸, 화면 밀도, 주요 작업 동선을 분리했습니다.
시안 구분 앱 셸 및 공간 배분 정보 밀도와 컨트롤 핵심 업무 흐름(Workflow) 중심 역할
C 기준안 (정제형) 좌측 고정 내비게이션 레일 + 우측 단일 캘린더 작업면 균형 밀도 (36px 기본 컨트롤, 4열 계기판 요약, 7열 주간·월간 셀) 잔여 연차와 개인 일정을 먼저 확인한 뒤 신청 동작으로 이동하는 표준 흐름 일반 직원 (STAFF)
C1 가용 매트릭스 좌측 사이드바 제거 + 상단 단일 바 + 전폭 다중 법인·팀 타임라인 표 고밀도 운영 격자 (32px 컴팩트 컨트롤, 일자별 가용 인원 합계 행 고정) 오늘과 향후 2주간 누가 근무 가능한지 즉시 파악하고 내 행 빈 셀에서 날짜 선택 컨소시엄 협업팀, PM
C2 인라인 워크벤치 비대칭 2단 분할 (좌측 주간 일정·대기 내역 / 우측 상시 신청 인스펙터) 실무 입력 밀도 (36px 입력창, 점심 제외 실시간 차감 계산기 내장) 모달 팝업 없이 일정을 대조하며 시간 생략 전일 매핑·차감 검증·대기 건 즉시 취소 수행 신청·변경이 잦은 실무자
C3 결재 원장 큐 상단 명령 스트립 + 상태 탭 + 고밀도 행 기반 결재·차감 원장 테이블 최고 목록 밀도 (32px 행 액션, 인라인 반려 사유 펼침, 4단계 데이터 상태) 팀장·PM이 대기 건을 일괄 심사하고 반려 사유를 행 안에서 즉시 기록·감사 대조 팀장 (TEAM_LEAD), PM, 관리자
