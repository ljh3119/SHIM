⏱️ 시간 정책 원칙

마스터 설정에 따른 연차 신청의 시간 계산 및 제약 조건입니다.

  • 연차 신청은 시작/종료 시각 기반으로 1건의 스냅샷으로 저장됩니다.
  • 입력 시각은 정책 단위 경계(30/60/120분)만 허용됩니다. (단, 하루 전체 신청 시 업무 종료 시각은 예외 허용)
  • 신청 구간이 정책 단위보다 짧거나 점심시간에 완전히 포함되어 실제 차감 시간이 0시간이면 신청이 제한됩니다.
  • 설정 단위는 입력 제어 기준이며, 실제 차감은 선택 구간에서 점심시간 제외 후 계산됩니다.
  • 하루 총 사용시간은 대시보드 및 캘린더에서 자동으로 합산하여 표시합니다.

📋 연차 신청 상태 설명

각 신청 건의 처리 상태를 뜻하며, 상태에 따라 집계(사용/잔여시간) 반영 여부가 결정됩니다.

  • 결재 대기: 결재 전 상태입니다. 아직 최종 확정되지 않은 대기 신청입니다.
  • 승인됨: 결재가 완료되어 연차 사용으로 최종 확정되었으며, 사용량에 반영됩니다.
  • 반려: 승인 거절된 상태입니다. 사용 시간 및 잔여 연차 계산에서 제외됩니다.
  • 신청 취소: 기존 신청을 철회·무효 처리한 상태입니다. 사용 시간 및 잔여 연차 계산에서 제외됩니다.
