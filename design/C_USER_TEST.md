# C 기본안 사용자 테스트

현재 브랜치는 `design/braun-linear-exploration`입니다. 구현과 검토가 끝난 뒤 아래 서버에서 C 기본안을 테스트합니다.

## 접속

- URL: http://127.0.0.1:8017
- 관리자: `admin`
- 직원: `staff_01`
- 팀장: `lead_park`
- PM: `pm_kim`
- 샘플 계정 비밀번호: 모두 `0000`
- 서버 관리 터미널: Herdr `shim_c_ui_preview` (`t2r`)

운영 DB와 별도로 새로 만든 샘플 DB를 사용합니다. 샘플 데이터에는 실사용 정보가 없습니다. 실제 데이터 경로와 실행 환경은 `scratch/c-ui-session.json`에 기록되어 있습니다. 이 파일과 DB는 Git에 포함하지 않습니다.

## 확인할 흐름

1. 직원으로 개인 달력의 월·연도 이동, 전일·반차 신청, 다중 날짜 선택과 신청 내역을 확인합니다.
2. 팀장·PM으로 팀 달력과 회사·팀 표시를 확인합니다. 결재 메뉴는 마스터 설정의 승인 필요 여부에 따라 달라집니다.
3. 관리자로 대시보드, 사원 관리, 종합 달력, 공휴일, 감사 로그, 마스터 설정을 확인합니다.
4. 브라우저 폭을 줄여 모바일 화면과 신청 모달을 확인합니다. 1023px와 1024px 경계에서도 달력이 나타나는지 확인합니다.
5. Tab 키로 버튼과 입력을 이동하고, 모달 닫기 후 포커스 복귀와 긴 이름·사유 표시를 확인합니다.

기존 CSS가 남으면 Ctrl+F5로 새로고침합니다. 승인 메뉴를 테스트하려면 샘플 서버의 관리자 마스터 설정에서 승인 필요를 켭니다.

## 종료와 재실행

Herdr의 `shim_c_ui_preview` 터미널에서 Ctrl+C로 정상 종료합니다. 데이터 폴더를 지우지 않으면 샘플 변경 내용은 유지됩니다. 다른 서버나 운영 프로세스는 종료하지 않습니다.

재실행할 때는 `scratch/c-ui-session.json`의 `data` 값을 `SHIM_DATA_DIR`에 지정하고 `.venv_review\Scripts\python.exe -m uvicorn src.app.main:app --host 127.0.0.1 --port 8017`을 실행합니다. `scratch/start-c-ui.ps1`은 실행할 때마다 새 샘플 데이터를 만듭니다.
